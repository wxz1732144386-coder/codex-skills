# LibTV 分镜提示词

直接细致拆解用户交给 Codex 的参考视频；需要 LibTV 提示词时，再把拆解结果与当次连线素材整理为可复制的中文提示词。参考视频不要求上传或连接到 LibTV。镜头数、时长、题材、拍摄方式和声音要求由当次任务决定，不套用固定镜头数或人物设定。本技能只做分析与写提示词；不上传素材、不调用生成接口、不消耗积分，也不声称提示词已经通过成片验证。

## 核对输入

1. 直接查看用户交给 Codex 的参考视频；若用户给的是分镜文本，则读取文本。提取总时长、画幅、人物和产品、实际镜头起止时间、动作、每段服装与发型、面部状态、背景、景别、剪辑、声音及明确排除项。逐段复看关键动作、换装和切点，不仅凭稀疏缩略图概括。区分视频中能看见或听见的事实与推测；保留用户指定的顺序和创作意图，不自行增加镜头或情节。
2. 若当次有 LibTV 连线图、节点截图或可核验的素材列表，逐个建立“实际引用标记 → 素材内容 → 允许控制的画面要素 → 不应带入的要素”映射。引用标记可采用当次界面已核实的 `@图片N`、`@视频N`，或用户明确提供且与当次素材对应的 `{{Mixed N}}` 等格式；不要把一种格式擅自改写成另一种，也不要按文件名、上次任务编号或上传顺序猜映射。截图只用于核号，不算生成参考素材。交给 Codex 拆解但未连接的参考视频绝不写成 LibTV 视频引用。
3. 若同时提供人物、服装、产品等原素材，查看它们以确认可见特征；文字、参考视频与图片冲突时指出具体冲突，不凭空补全看不清的包装印刷、服装结构或身份特征。没有连线图时，仍可用文字描述已核实的参考视频与素材，但不编造 `@` 编号。只有编号、素材职责或优先级的缺失确实影响正确交付时，才询问受影响的部分；确认前不要输出伪装成可一键复制的最终提示词。

## 整理时间轴与素材职责

- 以连续的 `[起点, 终点)` 区间覆盖总时长；首镜从 0 开始，末镜到总时长结束，各镜头无空缺、无重叠。用户给的是逐镜头分段时，不强行改成逐秒条目。逐镜头写清该段的造型与场景、景别与机位、人物和道具动作、视线或表情、动作结束状态；镜头内部的状态应能合理完成。
- 动作拆解要达到能重拍的细度：交代起始姿态、身体朝向、左右手各持什么及从哪里移动到哪里、道具与嘴或杯的接触顺序、视线和表情变化、动作结束状态；同时记下画面景别、机位是否移动、切点与下一镜如何衔接。对短镜头按动作阶段细分，必要时给出更细时间点，不为形式强制每秒一条。看不清的手、道具、声音或精确切点标为不确定，不猜测。
- 每个镜头单独记录可见造型：上衣与内搭的颜色、领口、袖子、层次和版型；头发颜色、长度、分区、扎法、刘海与散落发丝；确实可见的发带、卷发筒、发夹、项链等配饰。记录面部朝向、眼神、眨眼、嘴唇和表情的起止变化，以及脸在画面中的占比。背景写出能辨认的床架、柜子、玩偶等物件的位置、室内日夜感和光线方向或明暗。细节服务于区分镜头，不从模糊画面臆造材质、颜色、身份或小物件。
- 把人物身份与逐镜造型分开：若某张素材只负责脸，锁定其脸型、五官和人物身份；发型、服装、表情和背景由用户指定的职责或参考视频逐镜控制。若另有唯一服装素材，按其职责替换；当原视频多次换装而新素材只有一套衣服、用户又未说明保留哪种逻辑时，指出这一取舍，不擅自把多次换装压成一套或反过来。
- 给每份素材明确且有限的职责，例如体型、面部身份、产品外观或场景；同时写明需要排除的源素材元素。人物脸、身材、服装、场景和产品来自不同素材时，避免把一份素材的无关元素带入另一份职责。产品的开合、内容物及包装文字只写有依据或用户明确指定的内容。
- Codex 拆解的未连接参考视频用于确定镜头顺序、时长、动作、运镜、场景和声音；将可复现的信息直接写成文字时间轴。人物或产品若由新图片替换，按用户指定的替换范围处理，不把原视频中对应的外观、品牌或服装带入。不要写“参考视频中的动作”这类只有看到原片才能执行的指令。
- 核查动作是否能在分配时间内自然完成，尤其是取物、进食、穿戴、接触和多步骤转身。明显过满时，先指出具体镜头和冲突，建议保留总时长与顺序的可行调整方案；得到用户选择后再输出最终提示词，不悄悄改切点或删掉关键动作。
- 区分镜头内运动与镜头间剪辑。用户要求复刻的视频若在切点直接跳到另一造型、场景或景别，或用户明确要求硬切，就在逐镜开头与全片剪辑规则中写明干净利落的硬切，并保留核实的切点；不要用叠化、镜头内变装或连续推镜替代。若原片使用其他转场，则按可见事实和用户要求写。自拍、旁拍和镜面拍摄按实际设定写清持机手、机位和画面运动之间的关系；手机前置视角不自动意味着手机出现在画面里或人物必须持机。

## 最终提示词结构

按下列顺序组织为一条完整提示词，必要时压缩重复文字，不丢关键限制：

1. **成片规格：**总时长、画幅、风格和用户明确指定的平台设置；分辨率或模型未确认时不虚构，也不声称文字能更改 LibTV 界面设置。
2. **参考素材分工：**对当次已核实的连线素材，沿用准确的 `@图片N`、`@视频N` 或用户明确提供的 `{{Mixed N}}` 等引用格式，逐一注明允许参考和必须排除的元素；未连接的参考视频只以拆解后的文字进入时间轴，不编造视频引用。
3. **全片画面：**稳定的人物或产品身份、空间、光线、质感、构图和全片适用的连续性规则。
4. **分镜时间轴：**按连续起止秒数列镜头。每段按“切换/机位景别 → 服装发型与配饰 → 可辨认的背景和光线 → 脸部朝向、视线与表情 → 手、道具和身体动作 → 结束状态”写清；该镜头没有或看不清的要素不硬填。需要硬切时在每个切点明确写出。
5. **剪辑和声音：**只采用当次要求的转场、字幕、配乐、对白及环境音设置。
6. **避免出现：**针对当次素材和动作列有意义的错误，避免堆砌无关禁令。

默认先交付**详细视频拆解**，按实际连续时间段写明逐镜服装发型、面部与背景、动作、双手与道具、机位景别、切换和声音；再交付**一个中文代码块**，其中是一条完整可复制的 LibTV 提示词。用户只要求拆解时，只交付拆解；用户只要求提示词时，直接交付提示词。不能用简短概述替代动作与造型拆解，也不要把分析过程原样塞进提示词造成冗长。若时间、素材职责或编号有影响正确性的冲突，先说明已确认的拆解和具体冲突，只询问必要的映射或优先级；此时不输出伪装成最终可复制的提示词。

## 交付前检查

- 时间区间与总时长一致；切点顺序、镜头数、硬切要求、声音要求与用户提供的视频或分镜一致。
- 拆解足以让没看过参考视频的人理解每镜的衣着发型、面部状态、背景、光线与动作如何开始、完成和衔接；未观察到的细节没有被写成事实。
- 所有素材引用均来自当次已核实的 LibTV 连线或用户明确给出的当次对应关系，格式、编号、素材职责及排除项一致；没有把截图或仅交给 Codex 的参考视频当成已上传素材。若没有连线素材，提示词中不出现虚构引用。
- 检查原片中直接跳切的地方是否在提示词相同时间点写明硬切；造型、发型、背景和景别只在切点变化，同一镜头内保持稳定。
- 同一镜头内人物身份、造型、场景、道具大小和产品包装稳定；每个动作在镜头时长内可合理完成。
- 不把提示词约束说成已验证的生成效果。用户另行要求实际生成时，按当次 LibTV 配置与报价先行确认，再由相应生成流程处理。
