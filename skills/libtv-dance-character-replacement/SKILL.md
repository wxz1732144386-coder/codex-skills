# 擦边舞蹈替换人物

收到原舞蹈视频和 LibTV 目标生成节点的连线图后，用已连接的目标模特替换原舞者。模特清楚可辨时，连线图上的参考缩略图即可用于分配素材职责；单独提供的模特原图可用于核对细节。默认按 **Wan 3.0、720P** 写，画幅和目标时长跟原片，用户当次指定优先。这个技能的交付是提示词，分析和核对在后台完成，整个流程只读。

## 核对引用和范围

- 从**目标生成节点的参考区**核对素材类型、可见编号和内容，逐一对应原舞蹈视频、模特图及其他经用户指定的参考。按界面标记写 `@图片N`、`@视频N`；节点名、画布位置和素材上传顺序都不能用来推断编号。用户明确给出的当次引用可用。只发给 Codex 的本地原视频用来拆动作，若未连入 LibTV，就用文字写出可复现的动作和镜头，省去视频 `@` 引用。
- 明确连接的原视频可直接控制舞步和镜头。只有连线图且视频可明确引用时，按该视频的全段动作与镜头写提示词，省去无法核实的时间点和动作细节。素材号码、目标舞者或身份参考不清楚，且无法用当前资料解决时，只请用户补对应信息；目标模特只发给 Codex 而未接入生成节点时，请用户接入并给出实际引用编号。
- 默认将模特参考设为外观依据，锁定目标舞者的脸型五官、身形比例、发型和可见穿搭（含鞋和配饰，仅在原构图拍到时体现）。用户若指定只换脸、保留原服装、分图控制发型和穿搭等，逐项采用当次分工。开头给每条引用写清职责。原视频负责舞蹈、动作和表情时序、机位构图、运镜、原场景与剪辑，声音按当次要求及可核实的原片处理。原舞者的脸、发型、衣服及配饰不得覆盖指定的新造型；模特图的背景、拼版、展示姿势和拍摄角度不带入成片。多人原片只替换用户指明的舞者。

## 写舞蹈与连续性

- 原视频可查看时，先确认实际画幅、时长、镜头变化和关键动作。按动作段写起势、重心和移步方向、手臂与身体的先后关系、转身、卡点和收势，只写能核实且影响复刻的内容。区分舞者自己的位移和镜头运动；沿用原片左右方向、入画范围和裁切。原片一镜到底就写连续拍摄，有切点就保留顺序和已核实的切点，原片硬切就写硬切。看不清的步法、手势、被遮挡部位及声音细节不补写。
- 全片从首帧起是同一位目标模特。转身、侧脸、抬手遮脸和重新露出时继续匹配同一身份；头发、衣服和配饰可随动作自然摆动，但保持版型、结构和颜色连续。身体转向、支撑脚和重心按原舞步衔接，接地和遮挡关系自然；针对实拍中风险最高的动作约束手指粘连、脚底滑动、面部漂移或服装闪变。延续原片机位运动和背景透视，避免为了“稳定”写成锁死原有运镜或削弱动作幅度。
- 若画布上可见的画幅或时长与复刻目标冲突，在同一个代码块的规格行注明需手动设置的画幅与目标时长。时长档位未知时，写源片时长或需覆盖的目标，省去未经核实的档位。舞蹈从原片起势跟到收势，保持原速。声音按当次要求处理，若需沿用原声，则写成目标要求。

## 交付

默认直接给**一个可复制的中文代码块**。其中包含目标规格、已核实的素材引用及职责、舞蹈与原镜头要求、针对当次素材的稳定性约束。有必要时在同一块内加入简短时间轴。发出前核对当次节点编号、身份和穿搭来源、原片动作与镜头、声音要求，并清除未替换的占位符。
